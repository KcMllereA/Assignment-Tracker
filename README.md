# UT Assignment Tracker

A QOL assignment tracker for UT Austin coursework.

## Motivation

For the longest time I've been using a Google Sheets with a custom App Script to sort assignments by due date.
It's worked pretty well for a long time, but it lacks several features I want. Now I know I could probably just use Google's App Script and code it all into a Google Sheets or whatever, but that's not very fun, is it?

## Planned Features

* **Assignment List**
    - Sorted by due date
    - Separated by current status
        - Not Opened
        - Active
        - Completed
        - Overdue
    - Filterable by course
* **Calendar View**
    - Course section times
    - Assignment due dates
    - Planned assignment "work on" times
        - Designate X hours at H:MM to do an assignment
    - Outside events
        - Add any club/industry/social event, or even basic reminders like drinking water
    - Mark lectures as cancelled to clear up sections of the week for other tasks
* **Grades**
    - Keep track of your grades per assignment
    - Add grade formulas from a course's syllabus for accurate final grade calculations
* **Other Quality-of-Life Features**
    - Much planned
